Application Documentation

Overview and operational guide for Blossom Flora staff.

About This Application


Blossom Flora is a dedicated order management system designed for commercial sales teams across Europe. It allows authorized agents to register floral orders, calculate taxes automatically on the server, and consult historical orders.

Operations Menu Guide


  • 1. Create a New Order: Fill in customer contact information (name, address, email, phone) and select from 4 fresh flower products (Roses, Tulips, Orchids, Sunflowers). Enable quantity inputs to specify purchase amounts. The server calculates the total price with 21% IVA and records the transaction.

  • 2. View All Orders: Fetches all recorded orders from the system and displays them in a structured table with comprehensive column details.

  • 3. View Order by ID: Search for any specific order using its unique identifier code to inspect complete order details.
